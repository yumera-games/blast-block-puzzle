# iPhone 触覚スパイク（技術検証専用）

**これは本番機能ではありません。** 採用も確定もしていません。
ゲーム本体（`src` / 本番 `index.html` / 本番 CSS / Phaser 設定 / ゲームデータ）とは**完全に分離**しており、
本番のビルド成果物にも含まれません（`vite build` はリポジトリ直下の `index.html` だけを入口にします）。

## 目的

iPhone 15 Pro の **Safari 通常表示**と**ホーム画面追加表示**で、
**ネイティブアプリ化せずに**触覚が得られる範囲を確認します。

対象は Safari 18 以降の `<input type="checkbox" switch>` に対する触覚フィードバックです。

**ゲームのイベントから任意のタイミングで使用できることを前提にしていません。**
それが本当に可能かどうかを、これから確かめるためのページです。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 検証ページ本体 |
| `spike.css` | このスパイク専用のスタイル |
| `spike.js` | このスパイク専用のスクリプト |
| `manifest.webmanifest` | **ホーム画面追加の検証用。スパイク専用**で、本番アプリには追加していません |

外部ライブラリは使っていません。**外部通信・分析・トラッカー・広告はありません。**
マイク・カメラ・位置情報も使いません。非公開 API も脆弱性も使いません。

## 起動方法

リポジトリの直下で、静的サーバを立てて `tools/iphone-haptics-spike/` を開きます。

```sh
# 例：Python の標準機能だけで済ませる場合
python3 -m http.server 8080
# → http://localhost:8080/tools/iphone-haptics-spike/
```

```sh
# 例：この repo にすでにある Vite を使う場合（依存を足す必要はありません）
npx vite preview --host 0.0.0.0 --port 8080
# もしくは
npx vite --host 0.0.0.0 --port 8080
# → http://<PC の IP>:8080/tools/iphone-haptics-spike/
```

ファイルを直接開く（`file://`）でも動きますが、**ホーム画面追加の検証はできません。**
その場合は HTTP で配信してください。

## 同一 LAN 上の iPhone から開く方法

1. **PC と iPhone を同じ Wi-Fi に接続**します。
2. PC の LAN IP を調べます（macOS: `ipconfig getifaddr en0` / Linux: `hostname -I`）。
3. 上のコマンドを **`--host 0.0.0.0`（または `python3 -m http.server 8080 --bind 0.0.0.0`）** で起動します。
4. iPhone の Safari で `http://<PC の IP>:8080/tools/iphone-haptics-spike/` を開きます。

### HTTPS は必要か

- **Test A〜F の実行には HTTPS は不要です。** `http://` の LAN アドレスで動きます。
- ただし **`navigator.clipboard.writeText()` は安全なコンテキストを要求します。**
  `http://` では自動コピーが失敗することがあります。その場合はページ下部の JSON 欄を
  **長押しして全選択 → コピー**してください（そのためのフォールバックを入れてあります）。
- **ホーム画面追加**そのものは `http://` でも可能ですが、環境によって挙動が変わります。
  確実にしたい場合は HTTPS で配信してください（このスパイクは HTTPS を要求しません）。

## Safari 通常表示での確認手順

1. iPhone の Safari で上の URL を開きます。
2. 冒頭の「環境」で **`input の switch 属性：サポートあり`** と出ることを確認します。
   出ない場合、この端末・OS では Test A〜F は触覚の判定材料になりません。
3. **Test A** から順に実施します（下の「Test A〜F の順序」）。
4. 各テストで **感じた／感じない／不明**を選び、必要なら自由記入します。
5. **COPY RESULTS** を押して JSON を取得します。

## ホーム画面追加での確認手順

1. Safari で同じ URL を開きます。
2. 共有ボタン → **「ホーム画面に追加」**。
3. ホーム画面のアイコンから起動します。
4. 「環境」の **表示形態**が `home-screen（ホーム画面追加）` になっていることを確認します。
   （`display-mode` または `navigator.standalone` から判定しています）
5. **Test A〜F をもう一度、最初から実施**します。
   Safari 通常表示と結果が違う可能性があるため、**両方の JSON を別々に保存**してください。

## Test A〜F の順序

| 順 | テスト | 何を見るか |
| --- | --- | --- |
| 1 | **Test A：基準** | 表示されたスイッチを**指で直接**切り替える。Safari 本来の触覚が出るか |
| 2 | **Test B：同期操作** | 通常ボタンのタップと**同じユーザー操作の中で**スイッチを操作したとき |
| 3 | **Test C：短い遅延** | タップから**約 80ms 後** |
| 4 | **Test D：演出途中** | タップから**約 280ms 後**（COMBO 主爆発相当） |
| 5 | **Test E：二段予告** | 接続予告と主爆発を想定した**2 回** |
| 6 | **Test F：連続抑制** | 短時間に**6 回**（抑制もキューも入れていない素の挙動） |

**Test A で触覚が出ない場合、Test B〜F の結果は「この端末では方式そのものが使えない」ことを意味します。**
先に Test A を確認してください。

## COPY RESULTS の使い方

- **COPY RESULTS** を押すとクリップボードへ JSON をコピーします。
- 自動コピーに失敗した場合は、下の JSON 欄が自動で全選択されます。手動でコピーしてください。
- **外部へは一切送信しません。** 送信先も送信コードもありません。

## JSON の保存方法

コピーした JSON を、メモアプリやメール等でご自身の手元へ保存してください
（このページから送信する手段はありません）。
**Safari 通常表示とホーム画面追加で 1 本ずつ**、計 2 本を取ると比較できます。

## 保存（localStorage）について

- 回答と実行記録は **`localStorage` のキー `iphone-haptics-spike/v1`** へ保存します。
- **このスパイクのページ内だけ**で使います。本番アプリは localStorage を使っていません。
- 「**記録をリセット**」ボタンで削除できます。
- プライベートブラウズ等で保存できない場合は、その旨がページ下部に表示され、
  記録はページを離れると消えます。
- **端末を一意に追跡する識別子は作りません・保存しません。**

## 触覚の有無は自動判定できない

このページが自動で分かるのは「**コード上、スイッチの状態が切り替わった**」ことだけです。
**実際に触覚が発生したかどうかは、ブラウザから読み取る手段がありません。**

そのため各テストには **感じた／感じない／不明** の回答欄があります。
**触覚の有無は、あなたの実機回答だけで確定します。**
触覚が確認できないときに、音でごまかすことはしていません。
