## 1. 世界設定（案 A ＋ 補足案 D 統合）

### 1-1. 一文で伝わる作品像

> **古代の人々は、建築物や魔法装置を「造った」のではなく、植物・鉱物・光を組み合わせて「育てた」。**
> **その庭園文明は石化して眠り、七基の灯は沈黙した。**
> **現代の灯継は、石化した導脈を読み解き、七つの灯と失われた王国の記憶を回復させる。**

### 1-2. 世界の基本構造（正式採用）

**世界名は Luminavale（ルミナヴェイル）。**「灯の帳（ともしびのとばり）」を意味する。

- 世界には**七つの王国**があり、それぞれを**一基の「灯」**が支えていた。
- **灯は照明ではない。**記憶・生命・魔力を循環させる**巨大な生体結晶炉**である。
- 古代文明の建築・道路・観測装置・炉・都市は、**建設されたのではなく、種・根・鉱物・光を組み合わせて育てられた。**
- 現在、その大部分は**石化または休眠**している。
- 壁や床に見える**導脈の溝は、石化した根・葉脈・菌糸・結晶脈**である。装飾ではなく、かつて生きていた器官の遺骸である。
- 千年前、**七基の灯が同じ夜に沈黙**した。以来、**虚（うろ）**と呼ばれる霧が広がっている。
- **主人公は七基の灯を再点火し、失われた王国と最後の王都の名前を回復する。**

### 1-3. 「自然対文明」にしない（**設計上の厳守事項**）

**この世界では自然と文明は最初から一体である。**次の構図を作ってはならない。

- ✗ 自然を破壊した文明への報い
- ✗ 機械と魔法の対立
- ✗ 自然に還るべきだという主張
- ✗ 人工物 vs 生き物

**正しい構図**：文明そのものが生きていた。だから文明は壊れたのではなく、**眠っている**。修復とは、壊れた機械を直すことではなく、**眠った器官を目覚めさせること**である。

この一点が、案 A（企画時の呼称「学院＋七王国型」）と補足案 D（企画時の呼称「眠る庭／育った文明」）を統合する要である。

### 1-4. 灯（ともしび）

| 項目 | 設定 |
| --- | --- |
| **正体** | 生体結晶炉。七基。各王国に一基 |
| **機能** | 記憶・生命・魔力を循環させる。副産物として光る |
| **見た目** | 建物ではない。**地形と一体化した巨大な器官**。外からは丘・洞・塔・湖底の窪みに見える |
| **現状** | 七基すべてが沈黙し、石化している |
| **沈黙の理由** | **壊れたのではなく、当時の灯継たち自身が眠らせた**（第 4 章以降で判明） |
| **再点火の条件** | 配列盤（＝パズル盤面）に正しい配置を作り、石化した導脈を再接続する |

### 1-5. 虚（うろ）

| 項目 | 設定 |
| --- | --- |
| **正体** | 灯を眠らせるために使われた封の**副作用**。敵意も意思も持たない現象 |
| **作用** | **物を破壊しない。**名前・意味・使い方・存在した記憶を失わせる |
| **被害の見え方** | 建物は無傷のまま残るが、誰も扉の開け方を知らない。地図から地名が消える。人は死なないが、そこにいたことを忘れる |
| **描写の禁止事項** | **血・死・破壊・腐敗を描かない。**喪失は**静けさ・無音・色の不在**で表現する |
| **画面上の表現** | 背景・盤面外・霧・音の欠落で表現する。**ブロックの彩度を落とす表現は採用しない**（9-4 参照） |

### 1-6. 継星院（けいせいいん）（正式採用）

**継星院は学校ではない。**次の 6 機能を兼ねる施設である。

| 機能 | 内容 |
| --- | --- |
| **観測院** | 世界各地の灯の応答を観測する巨大な観測盤を持つ |
| **修復工房** | 持ち帰った石化標本を試験・修復する作業場 |
| **記録庫** | 千年分の遠征記録・断片文書を保管する |
| **標本庫** | 各地の結晶種・根・鉱物の標本を収める |
| **遠征拠点** | 遠征の準備と帰還の場所 |
| **灯継の養成施設** | 新人に古代装置の読み方を教える |

**作ってはならない要素（厳守）**：

- ✗ 寮制度・組分け・寮対抗
- ✗ 制服
- ✗ 杖を中心にした授業
- ✗ 呪文詠唱の練習
- ✗ 学年制・卒業試験・組分けの儀式

**主人公の立場**：**選ばれし者ではない。**古代装置の読み方を学び、現地で調査・記録・修復する**新人技術者兼記録者**である。予言も血統も関係しない。院長は運命を語らず、**依頼**として送り出す。

### 1-7. 魔法の原則（正式採用）

魔法は感情だけで何でも起こせる力ではない。次の原則を持つ。

1. **魔力は生命・鉱物・光の循環から生まれる。**無から生じない。
2. **魔法は「記譜（きふ）」により導脈へ流される。**
3. **記譜は文字ではない。**配置・接続・順序・共鳴によって成立する。だから紙に書き写せず、**その場で組むしかない**。
4. **パズル盤面は、古代の生体結晶炉の配列盤である。**
5. **正しい配置は、眠った導脈を再び成長させる。**壊れた部品を交換するのではなく、**育て直す**。
6. **強い魔法ほど、単発の爆発ではなく、複数の導脈が噛み合って自走する。**

この 6 番目が、**COMBO と CHAIN が単なる得点倍率ではなく世界観上の到達点である**理由になる。

### 2-2. COMBO と CHAIN の違い（画面文言）

**この 2 つは混同されやすい。**初見の子どもにも伝わる短文を定める。**色だけで区別させない**（9-3 参照）。

| | 画面に出す短文（日本語） | 画面に出す短文（英語） | 何が違うか |
| --- | --- | --- | --- |
| **COMBO** | **「ふたつの じゅつしきが つながった」** | **"Two workings joined."** | **プレイヤーが起こした**。二つの術式を隣り合わせに置いた結果 |
| **CHAIN** | **「どうみゃくが ひとりでに うごいた」** | **"The conduit moved on its own."** | **盤面が勝手に続いた**。消えた後に自動で次が起きた |

**区別の設計原則**：

- **COMBO＝「つながった」／CHAIN＝「ひとりでに」。**動詞で区別する。
- COMBO は**起きた瞬間**に表示する。CHAIN は**2 回目以降の連鎖から**表示する。**タイミングで区別する。**
- 色だけで区別しない。**COMBO は横方向の合流アニメーション、CHAIN は縦方向の積み上がりアニメーション**として、**動きの向きで区別する。**

| `rainbow` | **初灯**（正式採用） | はつひ | **Firstlight** | はつひ | 「ぜんぶの いろに なる まえの ひかり」 |

**画面短縮名は、HUD の目的表示・結果表示で使う。**正式名は物語・図鑑・標本庫で使う。

### 3-2. 図案の必然性（**なぜ今の形なのか**）

**「育った文明」設定によって、現在の 7 図案はすべて必然として説明できる。**これが案 D を統合した最大の実利である。

| 素材 | 現在の図案（変更しない） | 世界観上の機能 | **図案がその形である理由** |
| --- | --- | --- | --- |
| **灯実**`red` | 苺型の実。上部に葉冠、内部に種 5 個 | 生命魔力を蓄える | **灯は生きているものからしか魔力を取り出せない。**灯実は炉に供えるために**育てられた実**である。葉冠は摘み取られていない証（＝新鮮な魔力）。5 個の種は次の株になる |
| **苗床晶**`green` | 3×3 の格子。右下に独立した葉 | 耕地・根・葉脈を制御する栽培結界 | **3×3 の格子は古代の育成床そのもの。**九つの区画で異なる根を育て、互いに干渉させない結界。右下の葉は**この床が今も生きている**印（石化していない唯一の部分） |
| **水脈晶**`blue` | 波の渦、泡 3 個、しずく 1 個 | 水脈と記憶を運ぶ | **記憶は水に溶けて運ばれる。**渦は流れ、泡 3 個は**三つの支流**、しずくは**まだ流れ出していない一滴**（＝未読の記憶） |
| **星標晶**`yellow` | 太い五芒星 1 個 | 光と方角を定める | **育てるには光の方角が要る。**五芒星の 5 頂点は、古代の測量が用いた**五つの基準方位**。星は空の星ではなく**地上に据える標（しるべ）** |
| **記憶晶**`purple` | 単独のカット宝石＋右下の唐草 | 記憶を保存し、記録をたどる | **宝石が保存装置、唐草が索引。**唐草は装飾ではなく**記録をたどる導脈**そのもの。二つの巻きは「入口」と「出口」 |
| **双導術式**`rocket` | 氷色の双方向の縦矢印＋左右に金の輝き 2 個 | 二方向へ力を通す指向術式 | **記譜で書き上げた術式。**双方向なのは、導脈が**押すのではなく引き合う**ため。左右の金の輝き 2 個は**術式が正しく閉じている印**（片方だけなら未完成） |
| **八環術式**`bomb` | 中央シアン核・桃色環・金の 8 方向ロゼット | 中心から八方向へ循環を解放する放射術式 | **三層は炉の断面図。**中央シアン核＝炉心、桃色環＝循環層、金の 8 放射＝**八方へ開いた排出口**。8 という数は**七つの灯＋原点** |
| **初灯**`rainbow` | 縦長の種殻＋縦に 1 本の割れ目。内側に七色の屈折光、表面に同心の成長筋、下端に短い根（**登録済み**・4-8） | 七系統のどれにも属さず、すべての導脈を一時的に接続する | **殻は「七つの灯へ分かれる前」の状態そのもの。**割れ目は分かれはじめた最初の裂けめ、同心の成長筋は殻が育った年月を示す。**「建てずに育てた」世界で、始原の光が種の形をしているのは必然である**（4-3 の R-3 採用理由） |

**「なぜ苺なのか」への答え**：Luminavale の古代文明は建てずに育てた。**果実の形をした結晶は、この世界では最も自然な工業製品である。**灯実は野生の苺ではなく、千年前に**炉の燃料として品種改良された作物**の化石である。

**「なぜ格子なのか」への答え**：苗床晶の 3×3 格子は菓子型ではなく**耕地の区画**である。古代の農法がそのまま結晶になった。

### 3-3. 識別根拠（**変更禁止事項**・実測値付き）

以下は素材測定で確認済みの識別根拠であり、**世界観の都合で変更してはならない**。

| 制約 | 理由 | 実測の裏づけ |
| --- | --- | --- |
| **`blue` へ方向矢印を戻さない** | 双導術式（`rocket`）との混同 | — |
| **`rocket` 以外に大きな方向矢印を使わない** | 同上 | — |
| **`bomb` の 8 方向ロゼットを簡略化・削除しない** | `bomb` と `blue` は**色だけでは分離できない**（1 型 ΔE 1.7 ／ コントラスト比 1.12）。**8 方向ロゼットが唯一の識別根拠** | 形状差 81.9% で担保 |
| **`green` の 3×3 格子を崩さない** | `green` と `blue` は**色だけでは分離できない**（3 型 ΔE 9.1 ／ グレースケール比 1.01）。**波と 3×3 格子が唯一の識別根拠** | 形状差 76.5% で担保 |
| **`yellow` の五芒星を単独・太いまま保つ** | 5 頂点と 5 切れ込みが識別根拠 | DFT 5 次成分が支配的（比 1.56〜2.39） |
| **`red` の葉冠と苺本体の分離溝を保つ** | 葉冠が本体と融合すると苺として読めない | 分離度 中央値 0.36〜0.37 |
| **`purple` の宝石と唐草の間の地色を保つ** | 唐草が宝石の輪郭を分断すると単独宝石として読めない | 88% の行で分離、分離度 中央値 0.02 |

**`rainbow`＝初灯の識別根拠（`yellow`・`rocket` と色だけでは分離できない件）は 4-8 に追記した。**

**世界観の設定は、これらの識別根拠を強化する方向にのみ作る。**たとえば「八環術式の 8 という数は七つの灯＋原点」という設定は、8 方向を減らせない理由を物語の側からも固定する。

## 4. `rainbow` の正式設計

**現状**：`src/game/types.ts` に `SpecialKind = 'rocket' | 'bomb' | 'rainbow'` として実装済み。`src/data/combos.ts` に `rainbow+rocket` / `rainbow+bomb` / `rainbow+rainbow` を含む 6 種の COMBO が定義済み。**Small ／ Regular 素材とも制作・測定・登録が完了した（4-8）。**

**4-1 〜 4-7 は初版時点の設計仕様であり、そのまま保持する。採用結果と実測値は 4-8 に追記した。**

### 4-1. 役割（正式採用）

- **七系統のどれにも属さない。**灯実・水脈晶・星標晶・苗床晶・記憶晶のいずれの色でもない。
- **すべての導脈を一時的に接続できる。**ゲーム上の「任意の色として振る舞う」挙動が、そのまま世界観になる。
- **七つの灯が同時に共鳴したときだけ生まれる。**だから盤面では稀にしか出現しない。
- **虚が奪った色と名前を、一時的に結び直す。**これが物語上の意味であり、最終章の伏線になる。
- **「虹色のお菓子」「一般的な虹玉」にはしない**（厳守）。

### 4-2. 名称の決定

利用者から提示された 3 候補を含めて評価した。

| 候補 | 読み | 評価 | 判定 |
| --- | --- | --- | --- |
| **始原晶** | しげんしょう | 意味は正確。ただし**「しげん」が「資源」と同音**で、子どもには物資名に聞こえる | **不採用** |
| **原光晶** | げんこうしょう | 意味は正確。ただし**「げんこう」が「原稿」「現行」と同音**の頻出語。検索性も悪い | **不採用** |
| **七環晶** | しちかんしょう | **`bomb`＝八環術式と「環」が衝突する。**七環と八環は画面上で読み違えられる。役割も正反対（rainbow は接続、bomb は放射）なのに名前が似る | **不採用（最も危険）** |
| **初灯** | **はつひ** | 「はじめの灯」。**世界の中心語「灯」と直結**し、七基の灯が分かれる前の光であることが名前だけで伝わる。3 モーラで子どもが呼べる。「初日（はつひ）」という既知語と同音のため耳になじむ。英語 **Firstlight** も 2 音節で発音容易 | **第一推奨** |

**第一推奨：初灯（はつひ）／ Firstlight。**画面短縮名も「はつひ」。**（その後、正式採用となった。4-8）**

**留意点として記録する**：`red`＝灯実（ひのみ）と `rainbow`＝初灯（はつひ）は、**どちらも「ひ」で始まる 3 モーラ**である。HUD の目的表示で並んだ場合の読み違えは**実機で確認すべき未検証事項**とする（10-3）。

### 4-3. 造形案 3 案

**共通の必須条件**（すべての案が満たすこと）：

- 既存 7 素材のどれとも異なる外形・主要紋章
- 単純な虹・キャンディ・七芒星・丸い虹玉にしない
- `bomb` の 8 方向ロゼットと混同しない／`yellow` の五芒星と混同しない／`purple` の単独カット宝石と混同しない
- `rocket` 以外に大きな方向矢印を使わない
- **色だけに依存せず、色覚特性でもグレースケールでも形で識別できる**
- 35px で主要形状が読める
- 4 背景で実シルエット最外リングのコントラスト 1.55 以上を目標にできる
- 既存素材と同じ**左上光源**
- **高彩度の七色は内部の屈折光に限定**し、外形は白金・淡金・中明度の中性色を中心にする

#### 案 R-1：三層のプリズム柱

- **外形**：縦長。三角柱を 3 段、わずかに角度をずらして縦に積む。上端が尖り、下端が広い
- **主要紋章**：段と段の境界に走る 2 本の水平な稜線
- **色**：外形は白金。段の境界の内側だけに七色の屈折光が薄く見える
- **長所**：「七色が分かれる前」という意味が**プリズムという物で即座に伝わる**。大人に最も分かりやすい
- **弱点**：**`purple`（単独カット菱形宝石）と同じ「多面体」カテゴリ**。35px で細部が落ちると、縦長の宝石に見える危険
- **競合リスク**：`purple` **中**／その他 低
- **35px 耐性**：○（縦長で 3 段に割れていることは読める）

#### 案 R-2：交差する三弧の結び

- **外形**：3 本の太い弧が互いに編み合わさり、閉じた結び目を作る。全体は横長の楕円
- **主要紋章**：弧の交差点 3 か所
- **色**：弧は白金。交差点の内側にだけ七色
- **長所**：**独自性が 3 案で最大。**既存 7 素材のどれとも category が違う（塊でも星でも格子でもない）
- **弱点**：**線が細い。**35px で編みが潰れ、ただの輪に見える危険が最も高い。輪になると `bomb` の環と紛れる
- **競合リスク**：`bomb` **中〜高（潰れた場合）**
- **35px 耐性**：**△（3 案で最弱）**

#### 案 R-3：開いた種殻（たねがら）

- **外形**：縦長のアーモンド形の殻が、**縦に一本割れて左右へわずかに開いている**。中から光がこぼれる
- **主要紋章**：割れ目（縦の一本線）と、殻の表面の**同心の年輪状の筋**
- **色**：殻は白金〜淡金の鉱物質。**割れ目の内側だけに七色の屈折光**。外へは光が白のまま漏れる
- **長所**：**A ＋ D 統合設定と最も整合する。**「文明は育てられた」世界で、始原の光が**種の形**をしているのは必然。物語上も「七つの灯はここから分かれた」＝種から育ったという説明が図案と一致する
- **弱点**：**`red`（灯実）と同じ「有機物の塊」カテゴリ。**遠目で果実に見える危険
- **競合リスク**：`red` **中**／その他 低
- **35px 耐性**：**◎（縦長の白い塊に一本の光る割れ目、は最も潰れにくい構成）**

### 4-5. 第一推奨と制作指示書

### 4-6. Small 完成後に Regular へ展開する際の光学調整方針

**Small（35/39px）が合格してから Regular（46/50px）を制作する。**逆順にしない。これは既存 7 点で確立した順序である。

| 項目 | 方針 |
| --- | --- |
| **本体色** | Small から **ΔE 5 以内**を維持（実績：blue 0.4／ROCKET 2.3／BOMB 1.4／green 3.7／red 1.13／yellow 3.94／purple 3.44） |
| **外形の比率** | **変えない。**殻の縦横比・割れ目の位置・根の長さは Small と同一に保つ |
| **強化する点** | (1) 年輪状の筋を 3〜4 本から**5〜6 本へ増やす**（46px で数えられる密度） (2) 割れ目の縁の稜線を**明確化** (3) 内部の七色の帯を**分離させる**（35px では混ざってよいが、46px では層として読める） |
| **強化しない点** | 新しい装飾要素を足さない。46px で消える微細装飾を追加しない |
| **単純拡大でないことの指標** | 同一サイズへ縮小した画素比較で **ΔE 10 以上が 20% 以上**（実績：ROCKET 26.5%／yellow 25.7%／green 30.5%／purple 41.3%／BOMB 46.3%／red 47.3%） |
| **差の集中先** | 割れ目・年輪の筋・内部の七色の層へ集中していること。**色全体の変更で差を稼がない** |

### 4-7. 測定項目と合格条件

**既存 7 点と同一の手順で測定する。**測定規則は [`CANDY_KINGDOM_VISUAL_INTEGRATION.md`](CANDY_KINGDOM_VISUAL_INTEGRATION.md) 11-5 に確定済み。

| # | 測定項目 | 合格条件 |
| --- | --- | --- |
| 1 | ZIP / PNG の SHA-256 | 申告値と完全一致。不一致なら**測定を止めて受信値を報告** |
| 2 | 寸法・形式 | 1254×1254 / 8-bit / カラータイプ 6（RGBA） |
| 3 | 本体・余白 | 本体 926×926、余白 上下左右 164px |
| 4 | 半透明画素数 | 6,000〜18,000px |

#### 世界観側で守ること（**変更禁止**）

- **中央の割れ目は縦に 1 本のみ。消さない、閉じない、二つの塊に分離させない。**
- **表面の筋は同心の弧（年輪状）。斜めに交差する葉脈にしない。**制作の第 1 案は葉脈で不合格になった（12-6）。物語上も、初灯は葉ではなく**殻**である。
- **高彩度の七色は割れ目の内側に限定する。**外形は淡金のまま保つ。
- **大きな方向矢印を入れない**（`rocket`＝双導術式との混同）。
- **淡金を高彩度にしない。**`yellow`＝星標晶との色分離がさらに悪化する。

#### `yellow`・`rocket` との関係（3-3 の識別根拠に追加する）

| 制約 | 理由 | 実測の裏づけ |
| --- | --- | --- |
| **初灯の中央割れ目と縦長の殻を保つ** | 初灯と `yellow`（星標晶）は**3 型・グレースケールで色分離できない**（3 型 比 1.10 / ΔE 5、灰 比 1.29 / ΔE 9）。**「縦長の種殻＋縦の割れ目」対「太い五芒星 1 個」という形が識別根拠** | 形状差 61.4%（Small）／ 64.1%（Regular） |
| **初灯に方向矢印を入れない** | 初灯と `rocket`（双導術式）は**グレースケールで色分離できない**（灰 比 1.09 / ΔE 3）。**「縦長の種殻」対「太い双方向矢印」という形が識別根拠** | 形状差 72.9%（Small）／ 71.5%（Regular） |

**世界観上もこの二つは近い位置にある。**星標晶は「光の方角を定める」、双導術式は「二方向へ力を通す」、初灯は「すべての導脈を接続する」。**いずれも「向き・つながり」に関わるため、物語で並べて語られる機会が多い。**画面で並んだときに形で区別できることを、設定の側からも崩さない。

#### 未検証として残すこと

- **初灯の淡金の面が、昼背景へ溶けて見えないか。**本体色と昼背景のコントラストは **1.03〜1.12** と小さい。これは 4-7 の受け入れ条件に含まれていなかった項目であり、**新しい不合格条件としては追加しない**（理由は 12-7）。**人間プレイによる可読性の確認項目として残す。**
- **大表示（256px 以上）で、殻の下端と短い根が隣接タイルの図案と接近して見える場合がある**（12-8）。盤面サイズ（35〜50px）では生じない。**大表示 UI を設計するときに、余白または縁取りで分離する。**
- **`red`（ひのみ）と `rainbow`（はつひ）の呼称の聞き分け**（10-3 の 8 番）。
- **COMBO（`rainbow+rocket` / `rainbow+bomb` / `rainbow+rainbow`）で他素材と同時に光ったときの見え方。**

### 5-8. 第 7 章の「虚」の表現（**厳守**）

| 手段 | 具体 |

| 5 | **小さいサイズで金の光が泥状に融合しない** | 60px で光条どうしが繋がって塊にならないこと。**光条間の谷が隣接する光条の 70% 以下**を目安に実測 |
| 6 | **角丸マスク適用後も中心がずれない** | iOS の superellipse マスクと Android の円形マスクの両方を適用し、**紫晶の重心が中心から 2% 以内**に留まること |
| 7 | **明色・暗色のホーム画面背景で輪郭が失われない** | 白背景・黒背景・中間灰の 3 種に並べ、**四隅の暗部が背景と同化しないこと。**同化する場合は四隅の明度を上げる |

### 8-4. 七芒星を使わない理由（記録）

7 点の星形（正七角星）は、(1) 特定の信仰・思想体系の象徴として広く用いられており、(2) 一部の国で警察・保安官のバッジ意匠に近く、(3) 既存の大型ファンタジー作品に七芒の宗教紋章がある。**したがって正七角星は使用しない。**

**「7」を表す代替**：**長さの異なる 7 本の光条**（本アイコンで採用）、または 7 個の点を環状に配した意匠。いずれも星形ではないため上記の連想を避けられる。

## 9. 視覚・UI・音の共通ルール（正式採用）

### 9-1. 色

| ルール | 内容 |
| --- | --- |
| **高彩度色は基本的に結晶だけへ使う** | **画面内で最も彩度が高いのは常にブロック。**これによりブロックは「浮く」のではなく「主役に見える」 |
| **背景・建築・衣装・UI は低〜中彩度** | 石・木・布・真鍮の自然な彩度に留める |
| **メインカラー** | 夜藍 `#273e98` ／ 夜紫紺 `#2a1a5e` ／ 金（`#f0c24a` 前後）／ 深緑 |
| **補助色** | 昼ピーチ `#f9c8b0` ／ 昼淡ピンク `#fbd9e4`。**朝夕・水中の限定色として使い、常用しない** |
| **UI の強調色** | **金と白に限定する。**赤・緑の強調色を UI に使わない（ブロックと競合するため） |

### 9-2. 素材感と魔法表現

| ルール | 内容 |
| --- | --- |
| **主要素材** | **石（磨いていない）・真鍮・羊皮紙・粗い布・木・結晶。**プラスチック的な光沢を避ける |
| **魔法の形** | **直線・導脈・分岐・成長する根。**光は必ず**溝を伝うように**動く |
| **使わない表現** | ✗ 一般的な稲妻 ✗ 派手な渦 ✗ 虹の爆発 ✗ 魔法陣の回転 ✗ 光の玉の大量発生 |
| **光源** | **左上。既存ブロック 16 点と共有する。**背景・UI・キャラクターもすべて左上光源に揃える |
| **紋章の規則** | **円と直線のみで構成する。**動物・人・武器を紋章に使わない。**8 方向の等間隔放射は `bomb` 専用**とし、紋章では使わない |

### 9-3. UI と文字

| ルール | 内容 |
| --- | --- |
| **装飾書体は見出しのみ** | タイトル・章題・結果表示の大見出しに限る |
| **本文と目的表示は可読性優先** | 角ゴシック。装飾しない |
| **読み仮名** | **漢字には必要に応じて読み仮名。**目的表示は原則すべての漢字に付ける |
| **使わない** | ✗ 擬音の吹き出し ✗ 丸文字 ✗ 過剰なパステル |
| **枠** | 真鍮の細線＋角の留め具 |
| **ボタン** | 石板に彫られた凹み＋金の下線 |
| **盤面の枠** | **厚みと影のある石枠。**細い線にしない。枠が物質的であるほど、中の結晶の非現実さが正当化される |
| **盤面可読性の優先** | **演出より盤面可読性を常に優先する。**外縁コントラスト 1.55 以上・形状差 35% 以上を下回る演出は採用しない |
| **COMBO と CHAIN** | **色だけで区別しない。**動詞（「つながった」／「ひとりでに」）、タイミング（即時／2 回目以降）、動きの向き（横の合流／縦の積み上がり）の 3 つで区別する |

### 9-4. 音

| ルール | 内容 |
| --- | --- |
| **音楽の編成** | 弦（チェロ・ヴィオラ）＋木管（バスクラリネット）＋金属打（クロタル・チューブラーベル）＋人声のハミング。**シンセは補助のみ** |
| **使わない** | ✗ 明るいオーケストラのファンファーレ ✗ **電子的なビープ音** |
| **効果音の質感** | **石・金属・水・木を中心にする** |
| **ライン成立** | 金属の澄んだ一撃（短い） |
| **CHAIN** | **倍音が積み上がる。**回数が増えるほど上へ伸びる |
| **COMBO** | **低音の合流。**二つの音が一つになる |
| **子どもと大人の両立** | **短い反応音（即座に分かる）＋長い余韻（飽きない）を重ねる。**反応音は 100ms 以内、余韻は 800ms 以上 |
| **第 7 章** | **BGM を止める。**効果音だけが鳴り、ライン成立ごとに音が一つずつ戻る |

### 9-5. 既存の宝石質ブロックを世界から浮かせない方法（**最重要**）

登録済み 14 素材は**高彩度・高光沢・自発光的**である。**素材は変更しない**前提で、周囲の設計だけで馴染ませる。

1. **盤面を「装置の内部」にする。**結晶が光っているのは当然だという文脈を作る。石の枠に嵌まった結晶なら、光っていて自然。
2. **背景の彩度を落とす。**背景は石・木・布の低彩度に統一する。**画面内で彩度が最も高いのは常にブロックだけ**にする。
3. **盤面の枠を厚く、物質的にする。**厚みと影のある石枠に嵌める。
4. **同じ光源を共有させる。**既存 14 素材はいずれも**左上光源で統一されている**ため、背景側を合わせるだけでよい。
5. **結晶以外に高彩度の発光を置かない。**UI の強調色も金と白に限定する。
