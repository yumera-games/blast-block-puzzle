## 2. 登録原本の背景に関する決定

### 2-1. 決定

**登録原本を本番の白地・黒地・カード背景へ直接配置することを禁止する。**【確】

**灰色背景の削除や単純な色選択による透過化も採用しない。**【確】
輪郭に灰色の縁（フリンジ）が残るためである。

### 2-2. 根拠（実測）

登録原本は**全画素 α＝255**（世界観 12-2 の共通仕様）で、透明度を持たない。【確】
背景と接する非背景画素が `#808080` からどれだけ離れているかを測った結果：【確】

| 原本 | 輪郭画素 | 平均 \|Δ\| | \|Δ\| ≤ 12 の割合 |

| カイエ v3 | 9,213 | 3.39 | **97.4%** |
| リヴェル v3 | 5,859 | 3.75 | **96.9%** |
| ネイ 正面 v2 | 7,542 | 2.42 | **96.6%** |

**登録ラフを造形参照として、透明背景と本番表示寸法を前提に、制作側が別ファイルとして制作する。**【確】

### 3-4. 刻印の大きさと白ハイライト

**2A には刻印の寸法の実測値がない。**現行のグレーボックス実装にも刻印は入っていない
（`src/ui/` に刻印を描くコードはない）。
**2026-09-15 に、利用者が比較画像を目視して以下を 2B 最終候補として確定した**（根拠は 3-14）。

| 項目 | 2B 最終候補 | 理由 |
| --- | --- | --- |
| 刻印の描き方 | **中空**（輪郭線のみ。面を塗りつぶさない） | 5 形総当たりの最小相違度が塗り 43.5% に対し中空 53.1%（セル 35px）。人間目視でも 35px・46px の両方で 5 形を判別できた（3-14-4） |
| 刻印の外接 | **セル寸法の 50%** | 35px で 17.5px、46px で 23px。50% での実測が 3-14 の根拠値。**46% ではない**（初版の推奨値から変更） |
| 刻印の線幅 | **セル寸法の 7%**（最小 2px） | 31px で 2.17px、33px で 2.31px、35px で 2.45px、46px で 3.22px。1px では 3 倍表示以外で消える |
| 確認済みのセル寸法 | **31 / 33 / 35 / 46px**（2026-09-15 に追加確認） | **320×568 の実寸は 33px（目標 1 件）と 31px（目標 2 件）**であり、35px ではない。4 サイズすべてで下限 40% を満たす（3-15-2） |
| 刻印の色 | **ブロック面と同色相で `(Y+0.05)×1.35−0.05` まで持ち上げた色。色相を保ったまま届かない場合（blue・yellow）のみ白を混ぜる** | 白一色にすると legal preview（`#ffffff`）と競合する |
| 刻印とブロック面の輝度差 | **1.35 以上** | 2A 48 節は「輝度差 10 以上を刻印とみなす」で測っている。1.35 はその二値化に確実に載る値。実レンダの実測は 1.3527〜1.3597（3-14-6） |
| 白ハイライト | **ブロック上端 1 本、セル寸法の 6% の高さ、不透明度 0.35** | 立体感を出しつつ、 `#ffffff` の legal preview と混同させないため**面全体には広げない** |
| 白ハイライトを出さないもの | **特殊ブロック** | 初版の理由「本体が `#f6f8fa` で白に近い」は、特殊の面を `#7a8f98` へ変えた（3-15-3）ので成り立たない。**特殊に白ハイライトを出すかどうかは未確定**（3-15-9） |

**【要】** 刻印が「うるさい」か「足りない」かは実画面でしか判定できない。
2A 51-2 は A2-HW-R について「虹色感と華やかさが**弱すぎると判断される可能性**」を挙げている。
**盤面のエッジ量について**：2A 45 節の **3.84** は測定方法（カーネル・色空間・正規化）が
記録されていないため、**今回のハーネスの数値と直接比較できない。**
**3.84 を今回の別方式の数値へ置き換えない。**刻印がエッジ量へ与える影響は、
同一ハーネス内の「刻印なし → 塗り → 中空」の増加量として 3-14-7 に記録した。

**残す回帰検査**（2026-09-15 に測定定義を確定した）

実装後に、**トークン値ではなく実際のレンダリング結果**を測る。

**判定対象＝面平均。**【2B 最終候補として確定】

| 項目 | 定義 |
| --- | --- |
| 面領域 | `Mface − Mglyph − Mhi` |
| `Mface` | ブロックのシルエット（角丸矩形、インセット込み）を**縁幅 + 1px ぶん収縮**した領域 |
| `Mglyph` | 刻印だけを描いたマスクを **1px 膨張**した領域 |
| `Mhi` | 上端ハイライト帯 |
| 測定値 | 面領域の**線形 RGB 相対輝度の算術平均** |
| 情報表示 | 平均に加えて **5%点・中央値・95%点**も残す（合否には使わない） |
| 測定単位 | Canvas の**原寸** `getImageData`。ブラウザの拡大縮小を挟まない |

| # | 検査 | 下限 |
| --- | --- | --- |
| 1 | 黄ブロック / 隣接する空きセル（grayscale 後） | **1.30 以上** |
| 2 | 通常時の 5 色総当たりの最小（面平均） | **1.50 以上** |
| 3 | protan / deutan / tritan の 5 色総当たりの最小（Viénot を線形 RGB へ。面平均） | 各 **1.20 以上** |
| 4 | 空きセルの縁 / セル面（**実レンダリング画素**。面平均とは別条件） | **1.30 以上** |
| 5 | 盤面の中 / 盤面の外 | **1.30 以上** |

**縦に隣接する「上セルの最暗画素 / 下セルの最明画素」を合否条件にしない。**【確】
**理由**：実際の盤面では、隣り合う 2 つの**面が直接接することがない。**
面と面のあいだには必ず**面インセット 4% × 2 ＋ ブロック縁 8% × 2 ＝ セル寸法の 24%**
（セル 35px で 8.4px）が入り、その区間は縁色である。
縁は面に対して 1.71〜3.18、grayscale 後でも 1.31 以上（3-14-3）。
したがってこの 2 画素の比較は、**実際には接していない 2 画素を仮想的に並べた条件**であり、
面全体の識別性を代表しない。**参考値としてのみ記録する。**

**「縁があるから面色の不足を無条件に許す」という意味ではない。**
**検査 2・3（面平均）と検査 4（縁 / 面）は、それぞれ独立に満たす必要がある。**

検査する画面には次を**すべて含める。**トークン値だけで判定しない。

- グラデーション
- 刻印
- 縁
- ハイライト
- 影
- **特殊ブロックの発光あり／なしの両方**

測定のたびに、3-13 の再発防止の 7 項目を残す。

| 候補C-2（≡） | 中空 | 53.1% | 50.9% | 50.9% | 45.9% | 53.1% |

**下限 40% の根拠**：候補A 中空の通常マスクが 35px 53.1%／46px 50.9%、
アンチエイリアス込みで 45.9%。**40% なら AA 込み実測に対して 5.9 ポイントの余裕がある。**
旧 ● / ■ の 15.8% を明確に上回る。人間目視でも 35px・46px の両方で 5 形を区別できた。

**候補B を採らない理由**：塗りでは最小が 15.8% のまま変わらない（◆ を縦長にしても
最小の組は 赤 ● 対 緑 ■ であり、そこが動かない）。中空では候補A より高いが、
◆ の比率を変える必要が生じ、5 形の線の言語がそろわない。
**候補C-1 / C-2 を採らない理由**：相違度が候補A と**完全に同値**で、✚ を置き換える利点がない。
加えて ✕ は 2A 11 節の「置けない」表示（ハッチ＋×）と衝突する。

**測定方式の差についての記録**（数値を並べる前に必ず読むこと）

同じ「候補A・塗り」でも、**▲ の作り方で値が変わる。**

| ▲ の作り方 | 35px 最小 | 46px 最小 | 最小の組 |
| --- | --- | --- | --- |
| 正三角形 | 35.7% | 37.3% | 紫 ◆ 対 青 ▲ |
| **全幅の二等辺**（採用） | 43.5% | 47.6% | 赤 ◎ 対 緑 ■ |

正三角形にすると ◆ と ▲ が近づき、**最小の組が入れ替わる。**

canvas のラスタライズで測ると 43.5%／47.6% で、**同じ形でも 1.4〜3.4 ポイントずれる。**
**測定系をまたいだ値を、同じ尺度の比較として並べない。**

#### 3-14-6. 面グラデーション（2B 最終候補）

**`a = 0.04`。線形 Y を上端 ×1.04、下端 ×0.96。**

| a | 横隣接 通常 | protan | deutan | tritan |
| --- | --- | --- | --- | --- |
| 0.00 | 1.5501 | 1.2432 | 1.2843 | 1.2234 |
| 0.02 | 1.5485 | 1.2374 | 1.2787 | 1.2103 |
| **0.04** | **1.5475** | **1.2411** | **1.2789** | **1.2092** |
| 0.06 | 1.5420 | 1.2356 | 1.2709 | 1.2036 |
| 0.08 | 1.5407 | 1.2326 | 1.2774 | **1.1949**（下限割れ） |
| 0.10 | 1.5290 | 1.2311 | 1.2841 | 1.1807 |
| 0.13 | 1.5189 | 1.2311 | 1.2722 | 1.1802 |

**a = 0.06 ではなく 0.04 を採る理由**

- a=0.06 の横隣接 tritan は 1.2036 で、下限 1.20 までの余裕が小さい。
- a=0.04 なら tritan 1.2092 で、8bit 丸め・実装差・グラデーション位置の差への余裕が増える。
- a=0.08 では実際に 1.1949 まで下がる。
- A2-HW-R は盤面を画面内で静かに保つ必要があり、強いグラデーションを優先する理由がない。

**a = 0 にはしない。**上端ハイライトと穏やかな面変化を残す。

**刻印 / 面 の輝度比（a=0.04 の実レンダ、セル 35px）**：
purple 1.3574 ／ red 1.3597 ／ blue 1.3557 ／ green 1.3595 ／ yellow 1.3535。
いずれも下限 1.35 を満たす。
blue と yellow は**色相を保ったままでは (Y+0.05)×1.35−0.05 に届かない**ため、
白を混ぜて輝度を上げている（3-4）。

#### 3-14-7. 盤面エッジ量

**測定方法**：盤面の 8×8 セル領域のみ（外枠を除く）。
CSS `filter: grayscale(1)` と同じガンマ域の輝度加重でグレー化し、
(a) 前方差分 `sqrt(dx²+dy²)` の平均、(b) Sobel 3×3 の勾配強度 ÷8 の平均。

**2A 45 節の 3.84 / 4.19 とは測定方法が一致しない。**
2A は「局所勾配の平均」としか書いておらず、カーネル・色空間・正規化の記載がない。
**絶対値を直接比較しない。3.84 を今回の別方式の数値へ置き換えない。**
**主結果は同一ハーネス内の「刻印なし → 塗り → 中空」の増加量とする。**

| セル | 測り方 | 刻印なし | 塗り | 中空 | 中空 − 塗り |
| --- | --- | --- | --- | --- | --- |
| 35px | 前方差分 | 22.211 | 23.225（+4.56%） | 23.620（+6.34%） | **+1.70%** |
| 35px | Sobel | 20.469 | 21.447（+4.78%） | 21.766（+6.33%） | **+1.49%** |
| 46px | 前方差分 | 17.401 | 18.143（+4.27%） | 18.467（+6.13%） | **+1.78%** |
| 46px | Sobel | 16.562 | 17.350（+4.76%） | 17.626（+6.42%） | **+1.59%** |

**結論**

- 中空は塗りよりエッジ量がわずかに増える。増加は **1.5〜1.8%**。
- 盤面エッジ量の大半（約 94〜96%）は**セル縁・インセット・角丸・ハイライト**が作っている。
- **この差は中空を不採用にするほどではない、と人間が判断した。**

#### 3-14-8. 測定条件の宣言（3-13 の再発防止 7 項目に対応）

1. **対象**：一時領域で生成した Canvas。3-14-1 の 3 枚が目視資料。
   外部の保存画像を測っていない。バイト数・寸法・SHA-256 は 3-14-1 に記載。
2. **測定領域**：`Mface − Mglyph − Mhi`（3-9）。縁からの除外幅はセル 35px で 4px、46px で 5px。
   **外接ボックスによる除外ではなくマスクによる収縮**である
   （外接ボックスで除外すると、46px で角丸部分の縁色が測定域へ混入する）。
3. **中心 1 画素・領域平均・領域中央値の別**：合否は**領域平均**。
   5%点・中央値・95%点・最小・最大も併記する（3-14-2）。
4. **色変換式と適用先**：コントラストは sRGB を線形化した相対輝度。
   色覚変換は **Viénot / Brettel–Mollon (1999) の LMS 射影を線形 RGB へ**適用。
   grayscale は CSS `filter: grayscale(1)` と同じ**ガンマ域**の輝度加重。
5. **発光・グラデーション・刻印・縁の扱い**：グラデーション・縁・上端ハイライト・影を
   **含めて描画**し、面の測定では刻印と上端ハイライトを**マスクで除外**した。
   特殊ブロックは発光なしの状態のみ描画している（**発光ありは未測定**）。
6. **CSS 寸法と実ラスタ寸法**：`deviceScaleFactor = 1`、Canvas の**原寸** `getImageData`。
   ブラウザの拡大縮小を挟んでいない。比較画像内の拡大は最近傍で、測定には使っていない。
7. **再現できない値を合否条件に使わない**：2A 45 節の 3.84 は方法が記録されていないため、
   **合否条件として使わない**（3-14-7）。
