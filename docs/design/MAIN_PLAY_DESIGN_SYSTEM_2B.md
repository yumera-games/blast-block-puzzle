### 3-7. ● と ■ の冗長な識別（2B で必ず解決する 1 件目）

**問題**【確】：◆ ● ▲ ■ ✚ の 5 形のうち、**● red と ■ green の刻印は面積の 85% が重なる。**
相違度はセル 35px で **15%**、セル 46px でも **19%** までしか改善しない。
A2-HW-R と N1 で同値であり、**形の集合そのものの問題**である。
色があるときは赤と緑がコントラスト 2.26 倍（はしご 2 段）で分かれるが、
**色を落とすと冗長手がかりが失われる。**

2A が挙げた候補【確】：● を ◎（二重丸）にする／■ を ⬢ にする／
刻印ではなく縁の形（角の丸みの差）に変える。**いずれも未検証。**

**推奨案【推】：● を ◎（二重丸）に変える。**

| 理由 | 内容 |
| --- | --- |
| 相違度が上がる | ◎ は中心が空くため、■ との対称差が大きくなる。 **目標は相違度 35% 以上**（現状 3 番目に低い「◆ vs ● 22%」を超える値） |
| ほかの 4 対を壊さない | ◎ と ▲ ✚ ◆ はもともと 22〜41% 離れている |
| 実装が軽い | 刻印の描画だけの変更。ブロックの面色・縁色・はしごに触れない |
| 色数を増やさない | 形だけの変更 |

**代案【推】**：■ green を ⬢（六角）へ変える。●（丸）との対称差は ◎ より大きくなる見込みだが、
**⬢ は ◆（菱形）と近い**ため、そちらの相違度（現状 33%）が下がるおそれがある。

**【要】** どちらを採るかは、**刻印を実装して 5 形の相違度を測り直してから**決める。
測定方法は 2A 48 節と同じ（刻印あり／なしの差分マスクの対称差 ÷ 和集合）。
**測り直さずに「解決した」と書かないこと。**

### 3-8. 色覚 3 型（tritan）のコントラスト改善（2B で必ず解決する 2 件目）

**問題**【確】：A2-HW-R の色覚 3 型での 5 色最小コントラストは **1.16**。下限 1.20 を下回る。
（1 型 1.20 ／ 2 型 1.23 ／ 3 型 **1.16** ／ 1 型の最小 ΔE 25.91）
N1 は 1.06 でさらに悪い。**どちらの案も下限に届いていない。**

**制約**【確】：**通常ブロックの色数を増やさない。**輝度のはしご 1.50 は第 1 ラウンドから変えていない。

**推奨案【推】：はしごの比を 1.50 から 1.56 へ上げる。**

3 型は青〜黄の軸が失われるため、残る手がかりは**明度**になる。
現状 5 色は `L_0 + 0.05` から 1.505 倍ずつで、5 色目 `#f3bd1c` が L 0.555。
比を 1.56 にすると 5 色目が明るくなりすぎ、**3-9 の黄ブロック問題が悪化する。**
したがって **`L_0` を下げる方向**で調整する。

| 案【推】 | 内容 | 影響 |
| --- | --- | --- |
| **A（推奨）** | `L_0` を 0.068 → **0.055** へ下げ、比 1.50 のまま 5 色目を L 0.522 へ | 3 型のコントラストが上がり、 **黄ブロックが暗くなるので 3-9 も同時に改善する。**purple が暗くなるぶん `border strong` との差は要確認 |
| B | 比を 1.56 へ上げる | 3 型は改善するが 5 色目が L 0.60 超になり **3-9 が悪化する** |
| C | 形の冗長化（3-7）だけで補う | 色数も輝度も触らないが、**1.16 は 1.16 のまま**。条件を満たさない |

**【要】** 案 A で 3 型が 1.20 以上に届くかは、**実際にシミュレートして測り直すまで分からない。**
2A 34-7 と同じ方法（3 型変換後の 5 色の総当たりコントラスト）で再測定すること。

### 3-9. 黄ブロックと空きセル（2B で必ず解決する 3 件目）

**問題**【確】：色を落とした状態で、黄ブロック `#f3bd1c` と空きセル `#eeeaf0` のコントラストが **1.16**。
下限 1.30 を下回る。**盤面の一番上の段の黄ブロックが空きセルに溶ける。**
色があるときは 1.46 ある。

**推奨案【推】：3-8 の案 A（`L_0` を下げる）と、空きセルの縁の強化を組み合わせる。**

| 手段【推】 | 内容 | 期待 |
| --- | --- | --- |
| 1 | `L_0` 0.068 → 0.055 で 5 色目を L 0.555 → **0.522** へ | 黄 / 空きセルの比が上がる |
| 2 | ブロックの**縁**（黄は `#46762c`、L 0.14 台）を**必ず描く**。面だけで判定させない | 縁は空きセルと 3 倍以上離れており、 **色を落としても残る**（2A 49 節の「空きセルの縁 1.70」と同じ原理） |
| 3 | 空きセルの縁 `#c5b0ca` の線幅を**セル寸法の 4% 以上**にする | N1 のセル境界 4.38 の考え方を、 **常設の騒がしさを増やさない範囲で**借りる。A2-HW-R の現状は 1.69 |

**【要】** 手段 3 は盤面のエッジ量を上げる。**3.84 を超えないことを実測で確認する。**
超えるなら手段 1・2 だけで 1.30 に届くかを先に測る。

### 3-10. 特殊・COMBO・勝利の認知（2B で必ず解決する 4 件目）

**問題**【確】：[Phase 2C 人間評価](../evaluations/PHASE2C_HUMAN_EVALUATION.md)は
**「実装完了・教材効果未達」**で閉じており、「演出に気づかなかった」という結果が出ている。
A2-HW-R の特殊の目立ち方は **4.20**、COMBO は **4.58**。
N1 はそれぞれ **7.49 / 8.52** で、**A2-HW-R の 1.8 倍**ある。

**制約**【確】：**常設の盤面を騒がしくしない。**A2-HW-R の盤面エッジ量 3.84 を上げない。
N1 の黒地・常設シルバー縁・配色を混ぜない。

**推奨案【推】：常設の明るさではなく「時間・動き・局所の明暗差・音」で解決する。**

| 手段【推】 | 内容 | 常設の騒がしさへの影響 |
| --- | --- | --- |
| 1 | **特殊が生成された瞬間だけ**、その 1 セルの周囲をセル寸法の 15% ぶん暗く落とす（240ms、`ease-out`）。 明るくするのではなく**周りを落として相対的に浮かせる** | **0**（瞬間のみ） |
| 2 | COMBO の核 `#fba5d0` を、結ばれた 2 個の**中点**に出す（2A 42 節の規則）。 出る場所が動くこと自体が気づきの手がかりになる | **0**（瞬間のみ） |
| 3 | **音を必ず視覚と同一フレームで開始する**（2A 11 節の共通規則）。 special create は line clear より優先、combo は最高優先でダッキング | **0** |
| 4 | 勝利は**一瞬の虹を挟んで金へ収束**（`G-VICTORY` の stop 順。2A 42 節） | **0**（瞬間のみ） |
| 5 | 特殊ブロックの縁 `#0977a6` を**常設で 1 段太くする**（セル寸法の 5%） | **わずかに増える。要実測** |

**【要】** 「気づけるようになったか」は **2A 26 節・50 節が明記するとおり静止画では判定できない。**
**人間が実際に遊んで、演出に気づいたかどうかを確認する**までは解決したと書かない。
Phase 2C と同じ失敗を繰り返さないため、**縦切りの合格条件に「演出に気づいたか」を必ず入れる。**

### 3-11. 高彩度領域の制限（2B で必ず解決する 5 件目）【確】

世界観 9-1 の規則をそのまま維持する。**新しい規則を足さない。**

- **画面内で最も彩度が高いのは常にブロックと結晶（七基の灯）。**
- **背景・建築・衣装・常設 UI は低〜中彩度。**石・木・布・真鍮の自然な彩度に留める。
- **結晶以外に高彩度の発光を置かない。**UI の強調色も金と白に限定する。
- 通常時のオーロラは**濃度を抑える**：画面背景 30〜38%、HUD の各 stop **14% 以下**、
  盤面外周リングは線幅 1.5px 相当。【確】（2A 42 節）
- **盤面のセル内側に虹色を流さない。**【確】

### 3-12. レスポンシブ規則（320 / 375 / 393 / 430px）
