## 0. 参照元サイトについて（重要・未達成事項）

指示された参照元 **https://okashi-no-kuni.github.io/ には、このセッションからアクセスできなかった。**

```
host: okashi-no-kuni.github.io:443
kind: connect_rejected
detail: gateway answered 403 to CONNECT (policy denial or upstream failure)
```

このセッションの外向き通信はポリシー適用のプロキシを通る仕組みで、
**当該ホストは許可対象に入っていない。** 迂回は禁止されているため行っていない。

したがって、**本文書の「世界観 DNA」はサイトを読み取って抽出したものではない。**
**指示文そのものに列挙されていた項目**を DNA として採用した。
サイトの実物・配色・UI・キャラクター・国名の表記ゆれ・素材は**一切確認していない。**

- **公開サイトは変更していない。**（アクセスできていない）
- **公開サイトの画像はコピー・ダウンロード・再配布していない。**（同上）
- 本文書のモックは **HTML / CSS / SVG で新規に描いたもの**で、外部素材を含まない。

これは [開発方針](../DEVELOPMENT_POLICY.md) 第 2 節の
「Toon Blast / Block Blast の実物は確認していない」と同じ扱いにする。
**確認できていないものを、確認したかのように書かない。**

サイトを確認できる環境で、次を照合する必要がある（**未検証**）。

- 実際の配色が本案の推定と合っているか

| 城 | **夜のお菓子の城。**紫のアイシング屋根、**金の灯りの窓** |
| 地面 | 深い紫の丘＋暗い縞の道。マカロンとキャンディが散る |
| 盤面 | **シルバーのセル境界（4.38）と特殊のシアンの縁（7.49）は第 4 ラウンドのまま維持** |
| 枠 | 金の細線＋シルバーの対比リング。四隅は**きらめきと宝石** |
| ゴールド | **盤面外周・報酬・CHAIN・勝利のみ。**セルの中には出さない（黄ブロックと競合させない） |
| 完成 | **ぎんがゼリー**（紫→水色のグラデーション＋星） |

**「工業的な黒いパネル」「サイバー端末」に見せないために行ったこと**

- 地を**漆黒にしない**（相対輝度 0.005 のままだが、色相は青紫 258°）
- 空に**星・月・オーロラ・城の灯り**を入れ、無地の暗面を作らない
- 直線の細かい格子・等幅記号・走査線などの機械的な装飾を**使わない**
- 装飾は**波形（アイシング）・宝石・王冠・きらめき**という有機的な形に限る
- 仲間を夜も出す

**これが成功しているかは人間確認が必要（第 8 節）。**

## 5. 実測（背景と装飾を足しても盤面が読めるか）

**すべて実描画のピクセルから測定。** コントラストは WCAG 相対輝度比、ΔE は CIE76。

| 指標 | 昼（A2-HW-R CK） | 夜（N1 Night CK） | 下限 | 判定 |
| --- | --- | --- | --- | --- |
| 空きセル面 / セルの縁 | **1.69** | **4.38** | 1.30 | OK（第 4 ラウンドと同値） |
| ブロック面 / 隣のセル（通常のみ） | **1.46** | **1.45** | 1.30 | OK |
| 特殊 / 隣の通常ブロック | 1.28 / **ΔE 86.2** | 2.23 / **ΔE 126.8** | 1.55 **または** ΔE 45 | OK（ΔE で分離） |
| 特殊の縁 / 空きセル | **4.20** / ΔE 56.6 | **7.49** / ΔE 73.6 | — | 第 4 ラウンドと同値 |
| **盤面の外形 / 背景の境界** | **1.60** | **3.49** | 1.25 | OK |
| HUD の下地 / 文字 | **13.71** | **8.71** | 4.5 | OK |
| 目標帯の下地 / 文字 | **13.80** | **10.18** | 4.5 | OK |

### 背景が盤面より強くなっていないか

| 領域のエッジ量（局所勾配の平均） | 昼 | 夜 |
| --- | --- | --- |
| **盤面** | **4.76** | **11.43** |
| **空の帯（背景が最も見える場所）** | **3.42** | **5.65** |
| 画面全体 | 4.87 | 7.18 |

**どちらの案も、背景（空の帯）は盤面より静かである。**
盤面 4.76 > 背景 3.42（昼）、盤面 11.43 > 背景 5.65（夜）。
背景が盤面と competing していないことを、印象ではなく数値で確認した。

なお第 4 ラウンドでは昼の盤面 3.84・画面全体 4.19 だった。
**今回、盤面のエッジ量は 3.84 → 4.76 に増えている**（砂糖の粒・照り・波形を足したため）。
盤面自体は前より賑やかになった。**これが過剰かは人間確認が必要**（第 8 節）。

### 演出中に盤面が読めるか

**演出が当たっているセルと、当たっていないセルを分けて測った。**

| 状態 | 盤面で変化した面積 | 当たっているセル | **当たっていないセル** |
| --- | --- | --- | --- |
| 昼・消去中 | 13.5% | 縁 1.05・ブロック 3.10 | **縁 1.69 OK・ブロック 1.46 OK** |
| 昼・錬成中 | 30.7% | 縁 1.08・ブロック 1.02 | **縁 1.69 OK・ブロック 1.53 OK** |
| 夜・消去中 | 13.8% | 縁 1.09・ブロック 2.86 | **縁 4.38 OK・ブロック 1.45 OK** |
| 夜・錬成中 | 37.4% | 縁 1.12・ブロック 1.10 | **縁 4.33 OK・ブロック 1.45 OK** |

演出が当たっているセルは、**意図どおり覆われて手がかりが落ちる。**
**演出の外側のセルは、通常時とまったく同じ読みやすさを保っている。**
つまり演出は局所的であり、盤面全体を洗い流してはいない。

**注意：** この「変化した面積」は第 4 ラウンドの遮蔽率（透明キャンバスの平均 α）とは**別の測り方**で、
数値を直接比較してはならない。

## 6. 5 秒テストの自己判定

| # | 条件 | 自己判定 | 根拠（画面上の何が担っているか） |
| --- | --- | --- | --- |
| 1 | **魔法の世界である** | **達成と考える** | 虹／オーロラ、きらめき記号、光る特殊、王冠と宝石、浮かぶ光の演出 |
| 2 | **お菓子の国である** | **達成と考える** | アイシング屋根の城、キャンディの道、包み紙のキャンディ・マカロン・ワッフル・星のクッキー、ガラスのデザート台 |
| 3 | **明るく夢のある冒険である** | **昼は達成と考える。夜は要確認** | 昼＝高明度の空・虹・雲・仲間。夜＝暗いので「明るい」は成立しない。**夜は「同じ世界の夜」であることが条件**（下記 4） |
| 4 | **盤面と操作方法が明快である** | **達成と考える** | 8×8 の格子が全幅を占め、トレイの 3 枠が下にあり、セルの縁は 1.69 / 4.38。実測はすべて下限以上 |
| 5 | **通常国と夜の特別国の違いが分かる** | **達成と考える** | 空の色（0.90 対 0.005）、星と月の有無、城の色。同じ骨格・同じ城の形なので**同じ世界の昼と夜**に見える |

### 背景を消した対照

同じ画像の右 2 列が「**文字も背景も消した状態**」である。

- 背景を消すと、**条件 1 と 2 の手がかりが大きく減る。**
  残るのは、お菓子ブロック・特殊・王冠・金の枠・仲間・ガラスのトレイ。
- **つまり世界観の相当部分を背景が担っている。**
  これは狙いどおりだが、**背景が出せない場面（モーダル全画面、演出の暗転など）では
  世界観が弱くなる**ことを意味する。第 4 手順（2B）で扱う必要がある。

### 自己判定として達成できていない点

- **「5 秒以内に伝わるか」は測っていない。** 提示時間を制御した評価をしていない。
- **初見かどうかを制御していない。** 制作者は答えを知っている。
- **夜が「明るく夢のある冒険」に見えるかは、条件として矛盾を含む。**
  夜は暗いので、明るさではなく**「同じ世界」であること**で担保する設計にした。
  この読み替えが妥当かは人間が決めることである。

## 7. キャラクターの扱い（仮スロット）

**完成版キャラクターは別チャットで制作中のため、具体的なデザインを固定しない。**
本案が決めたのは「**入る場所と、そこに何のくらいの大きさで何が出るか**」だけである。

| スロット | 場所 | 出るとき | 本案での扱い |
| --- | --- | --- | --- |
| **盤面を見守る小さな仲間** | 空の帯の左（城の前） | 常時 | **試作した**（昼・夜とも） |
| **成功時に登場する仲間** | 勝利カードの右上 | 完成時のみ | **試作した**（表情が変わる） |
| 目標のお菓子を示す案内役 | 目標帯の左 | 常時 | 現在は**お菓子の絵**を置いている。キャラクターに差し替え可能 |
| 背景の国で待つキャラクター | 城の周辺 | 常時 | **未試作** |

**灰色の人物型プレースホルダーは使っていない。**
丸い体・キャンディの耳・星のきらめきを持つ**お菓子の仲間のシルエット**にしてある。

**これは完成キャラクター素材ではない。**
色・形・表情・比率はすべて仮であり、本編のキャラクターが確定した時点で差し替える。
**本編のキャラクター名・デザインは、この文書では一切確定していない。**

## 9. 未検証事項

| 区分 | 内容 |
| --- | --- |
| **確認できていない** | **参照元サイトの実物**（403 で到達不可）。配色・造形・国名の正式表記・キャラクターの方向 |
| **人間にしか判定できない** | 5 秒で伝わるか／着せ替えに見えないか／夜が機械的に見えないか／城の造形の妥当性／賑やかさの許容度／気持ちよさ |
| **測っていない** | 提示時間を制御した認識テスト。初見プレイヤーの反応。視線の行き先 |

| **未設計** | 背景が出せない場面（全画面モーダル・暗転）での世界観の担保。国ごとの背景差し替えの仕組み。特別ステージのルール変化 |
| **方法上の限界** | エッジ量は局所勾配の平均であり「賑やかさ」の知覚そのものではない。形の相違度は二値マスクの比較であり人間の弁別能力ではない |
